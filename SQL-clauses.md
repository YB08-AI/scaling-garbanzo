# 📘 SQL Study Aids

This folder contains concise bilingual (English ↔ Arabic) cheat sheets for key SQL clauses.  
Designed to help learners quickly understand and apply SQL concepts in both languages.

---

## 🔹 SQL Clauses Cheat Sheet (English ↔ Arabic)

| SQL Clause     | English Meaning                                | Arabic Translation       | Example |
|----------------|-----------------------------------------------|--------------------------|---------|
| `GROUP BY`     | Groups rows with the same values in columns    | **تجميع حسب**            | `GROUP BY dep_month` → تجميع حسب شهر الرحلة |
| `ORDER BY`     | Sorts the result set by one or more columns    | **ترتيب حسب**            | `ORDER BY dep_day_of_week` → ترتيب حسب يوم الأسبوع |
| `HAVING`       | Filters groups after aggregation               | **شرط على المجموعات**    | `HAVING COUNT(*) > 10` → شرط أن عدد الصفوف أكبر من 10 |

---

## 🧩 Quick Notes
- **GROUP BY** → Collects similar rows together.  
- **ORDER BY** → Sorts the output neatly.  
- **HAVING** → Applies conditions after grouping.
